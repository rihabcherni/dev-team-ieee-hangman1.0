# Hangman Game

A web-based Hangman game that brings the classic word-guessing experience to life with multiple difficulty levels, hints, and interactive gameplay.

## Project Overview

This project transforms the traditional Hangman game into an engaging web experience with enhanced features and an intuitive interface:

- **Multiple Difficulty Levels**: Choose from Easy, Medium, or Hard modes to match your skill level
- **Progress Tracking**: Monitor your score and level progression throughout your gaming session
- **Strategic Tools**: Use bombs and hints strategically to guess words more effectively
- **Audio Experience**: Immersive background music and sound effects for correct and incorrect guesses
- **Personalization**: Login feature with avatar selection to customize your gaming experience
- **Comprehensive Support**: Help and About sections provide gameplay guidance and IEEE CS Club information

## Features

- **Interactive Gameplay**: Guess the hidden word before the hangman drawing is completed
- **Adjustable Difficulty**: Three challenging modes to suit different skill levels
- **Strategic Elements**: Hint system and bomb feature for tactical word solving
- **Score System**: Real-time score tracking and level progression mechanics
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices
- **User Profiles**: Login system with customizable avatar selection
- **Information Hub**: Dedicated Help and About sections for user guidance
